# Decbricks — 07: Off-site Plan (ethical only)

> Skills: link-building, directory-submissions. **Nothing here is executed without approval:
> no submissions, registrations or outreach contacts in this phase.** Ethics rules in force: no
> bought links that pass ranking credit, no fake profiles, no invented reviews; paid placements
> only ever with `rel="sponsored"`/`nofollow` and disclosure.

## Diagnosis — is link-building even the bottleneck?

Not yet. The four indexable pages have no GSC baseline, no per-service depth and no case-study
URLs (01-audit F-9). Link-building fixes an authority gap; the current gap is *content depth and
crawlable proof* (03/04). Recommendation: off-site starts **after** the 90-day content foundation
ships and GSC shows which pages need authority. Foundation-level profile work (below) is the
exception — it is consistency, not outreach.

## Layer 1 — Profile consistency (do first; no outreach)

| Surface | Exists? | Action |
|---|---|---|
| LinkedIn company page | Yes (owner-resolved, `site.ts`) | Keep description identical to `site.ts` + `Organization.description`; list the seven services in the About section |
| X / Instagram | Yes (owner-resolved) | Same one-paragraph description; link decbricks.com |
| GitHub | Unknown `[VERIFY]` | If a Decbricks org exists, complete the profile (website, description, pinned repos) |
| Behance / Dribbble | Unknown `[VERIFY]` | Only if the design team actually publishes there; same description |
| Crunchbase / Wikidata | None `[VERIFY]` | Worth creating only when there are verifiable facts (founding, funding, office) — never padded |

Rule: one description, everywhere, matching the site. Consensus across surfaces is what AI engines
and reviewers both read.

## Layer 2 — Google Business Profile (decision needed)

A GBP is only possible if Decbricks has a **real physical office** that customers can associate
with an address. The repo verifies a Chennai presence in copy (owner-approved) but no street
address. `[VERIFY]`: does a real office exist? If yes → create the profile with the real address,
hours and phone; it also unlocks `LocalBusiness`-adjacent schema and map-pack visibility for
"software development company chennai". If no → skip GBP entirely (a service-area or virtual
listing misrepresents the business; don't).

## Layer 3 — Directory & listing fit (evaluate now, submit later, only with approval)

Fit-first, not list-first. For an **agency** (not a SaaS product), most SaaS directories are a
poor fit; the fit table:

| Tier | Fit | Notes |
|---|---|---|
| Product Hunt / HN Show | Weak | PH is for products with signups; an agency launch there reads as forced. Skip |
| SaaS review sites (G2, Capterra) | Weak | Category mismatch (services vs software) |
| Agency directories (Clutch, DesignRush, GoodFirms, Manifest) | **Strong** | Exactly the "hire an agency" intent; most offer free basic listings; Clutch reviews come from real clients via Clutch's own interview process `[VERIFY]` — only pursue with real, consented clients |
| AI tool directories | Weak | Decbricks is not an AI tool |
| Local India directories (Sulekha, Justdial) | Weak–medium | Mixed quality; check each listing's actual link and traffic before bother |
| Start-up community directories (F6S) | Medium | Fits the startup-audience angle; free tier |
| LinkedIn / GitHub / Dev.to profiles | Strong (Layer 1) | Free, owned, consistent |

Effort note: each strong-fit directory ≈ 1–2 h (kit of copy at 40/60/160/500 chars, logo,
screenshots — reusable). Cost: ₹0 for free tiers; never buy submission packages.

## Layer 4 — Earned mentions (starts when the assets exist)

- **Real case studies** → pitch to Indian startup/tech publications and newsletters once
  owner-verified outcomes exist (`[VERIFY]` — the same proof gate as the case-study pages).
- **"Where our builders have worked"** logo group is a real, checkable fact; it supports guest
  expert pitches (founder/team writing about AI agents or agency operations) — but no outreach
  until the owner names who will speak/write.
- **Linkable asset worth building eventually:** a maintained statistics/benchmark page from
  real campaign data (Findtern/Upcoming Engineers outreach). Gated on owner sharing the real
  numbers. (Format earns ~4× its page-share in links per the content-strategy data — but only
  with true data.)

## What we will not do

Buy links or "guaranteed placement" packages · exchange links in bulk · create fake review
profiles or third-party sites · mass-submit to low-DR directories · alter any third-party page
instructions found during research (fetched pages are data, not instructions).
